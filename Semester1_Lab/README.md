## Метод Ньютона

Метод Ньютона (метод касательных) — это численный метод нахождения корней нелинейного уравнения
𝑓(𝑥)=0
путём последовательного уточнения приближений с использованием производной функции.

Идея метода (интуитивно)

В текущей точке x_n функцию f(x) заменяют её касательной. Точка пересечения касательной с осью 𝑂𝑥 принимается за следующее приближение 𝑥_𝑛+1.
Геометрически:

берём точку 
проводим касательную,
смотрим, где она пересекает ось 

#include <iostream>
#include <cmath>

const double epsilon = 1e-6;

double f(double x) {
	double y = x - (1 / (3 + sin(3.6 * x)));
	return y;
}

double dif1_f(double x) {
	double y = 1 + (3.6 * cos(3.6 * x)) / ((3 + sin(3.6 * x))* (3 + sin(3.6 * x)));
	return y;
}

int main() {
	double a = 0, b = a - (f(a) / dif1_f(a)); //a - нач. приближение
	while (fabs(b - a) > epsilon) {
		a = b;
		b = a - (f(a) / dif1_f(a));
	}
	std::cout << b;
	return 0;
}

#include <iostream>
#include <cmath>

const double epsilon = 1e-6;

double f(double x) {
	double y = x - (1 / (3 + sin(3.6 * x)));
	return y;
}

double g(double x) {
	double y = (1 / (3 + sin(3.6 * x)));
	return y;
}

int main() {
	double x0 = 0.85, x1 = 0;
	x1 = g(x0);
	while (fabs(x1 - x0) > epsilon) {
		x0 = x1;
		x1 = g(x0);
		}
	std::cout << x1;
	return 0;
}

## Метод половинного деления

Дано: 1) нелинейное уравнение 2) интервал A - B (там будет корень) 

Если на концах отрезка функции значения разные 
1) Проверка в алгоритме наличие того что на интервале A - B есть точка f(A) и f(B) имеют разные знаки f(A) * f(B) < 0 (если интервал то < если нет то <=) 
2) Иначе если f(A) * f(B) > 0 то корня на отрезке A - B нет 
3) Плюсы метода: 
Гарантирован результат, если соблюдены все условия: 
а) если функция на интервале монотонна (проверить можно производной) постоянно возрастающая или убывающая, т.е. знак первой производной не меняется (либо всегда < 0 либо всегда >) 
б) функция непрерывна (проверка области определения,  
4) Минусы метода: 
Метод равномерный по времени в каждой итерации нахождения очередного корня xi
5) Алгоритм метода: 
1. Начальная точка x0 берется на середине интервала A – B, x0 = (A + B)/2 
2. Проверяем интервалы Ах0 и Вх0 и отбрасываем тот в котором нет корня: 
3. Проверяем значение функции в точках:
f(A) f(x0) f(B) 

а) Перемножаем f(A) * f(x0): <0 

б) Перемножаем f(B) * f(x0): <0

 - И выбираем тот где произведение отрицательно (путем переноса границы B вправо на x0 либо A на х0) 
Отбрасываем путем переноса границы (уже новый центр f(х0) f(x1) f(B) )
 ответ: 0.262441

#include <iostream>
#include <cmath>

const double epsilon = 1e-6;			

double f(double x) {
	double y = x - (1 / (3 + sin(3.6 * x)));
	return y;
}

int main() {
	double a, b, c;
	a = 0;
	b = 0.85;
	while (b - a > epsilon) {
		c = (a + b) / 2;
		if (f(a) * f(c) < 0) {
			b = c; 
		}
		else {
			a = c;
		}
	}
	std::cout << (a + b) / 2;
	return 0;
}
