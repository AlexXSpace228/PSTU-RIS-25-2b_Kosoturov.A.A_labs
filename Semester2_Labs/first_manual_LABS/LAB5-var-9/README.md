# Постановка задачи

1. Реализовать функцию вычисления суммы элементов квадратной матрицы, расположенных ниже главной диагонали.  
2. Организовать формирование нескольких квадратных матриц заданного размера.  
3. Для каждой матрицы определить соответствующую сумму.  
4. Найти максимальное значение таких сумм среди заданного количества матриц.  
5. Вывести результаты работы программы в консоль.  

---

# Анализ задачи

В рамках поставленной задачи рассматриваются квадратные матрицы порядка `n`, представленные в виде двумерных массивов целых чисел фиксированного размера `20×20`.

---

# Элементы ниже главной диагонали

Главной диагональю квадратной матрицы называются элементы, для которых выполняется условие:

```text id="32nqvx"
i = j
````

Элементы, расположенные ниже главной диагонали, определяются условием:

```text id="ksmwsj"
i > j
```

Следовательно, для вычисления требуемой суммы необходимо организовать вложенный цикл, в котором индекс строки превышает индекс столбца.

---

# Формирование матриц

Размер матрицы `n` и количество матриц вводятся пользователем с клавиатуры.

Заполнение матриц осуществляется с использованием датчика случайных чисел `rand()`.

Значения элементов формируются в диапазоне от `−50` до `49`, что позволяет обеспечить наличие как положительных, так и отрицательных значений.

---

# Вычисление суммы элементов ниже главной диагонали

Для решения данной задачи реализована функция:

```cpp id="m0y7g7"
int CountSummDig(int M[][20], int n)
```

Функция выполняет следующие действия:

1. Последовательно перебирает строки матрицы, начиная со второй (индекс `1`).
2. Для каждой строки суммирует элементы с индексами столбцов от `0` до `i−1`.
3. Вычисляет частичную сумму для каждой строки.
4. Определяет максимальное значение среди полученных сумм.
5. Возвращает найденное максимальное значение.

Таким образом, функция реализует алгоритм вычисления суммы элементов, расположенных ниже главной диагонали, с последующим определением максимальной строки по данной характеристике.

---

# Определение максимального значения среди матриц

В основной функции программы:

1. Для каждой из заданных матриц вызывается функция `CountSummDig()`.
2. Возвращаемые значения сохраняются в массив `MaxCounter`.
3. После обработки всех матриц выполняется поиск максимального значения в массиве полученных сумм.
4. Результат выводится в консоль.

Для вывода используется функция `PrintMass()`, которая одновременно отображает элементы массива и определяет максимальное значение.

---

# Описание алгоритма

Алгоритм работы программы включает следующие этапы:

1. Ввод размера матрицы `n` и количества матриц.

2. Для каждой матрицы:

   * генерация случайных элементов;
   * вывод матрицы;
   * вычисление суммы элементов ниже главной диагонали;
   * сохранение результата.

3. Вычисление максимального значения среди полученных сумм.

4. Вывод результатов в консоль.
