# Лабораторная работа  
## Преобразование строки в идентификаторы

---

# Постановка задачи

Разработать программу, выполняющую преобразование строки таким образом, чтобы:

- все слова стали корректными идентификаторами;
- слова, состоящие только из цифр, удалялись;
- строка содержала только допустимые символы идентификаторов;
- повторяющиеся пробелы удалялись.

---

# Анализ задачи

В рамках работы рассматривается строка произвольной длины, вводимая пользователем с клавиатуры.

После обработки строка должна удовлетворять следующим условиям:

1. Слова, содержащие только цифры, должны быть удалены.
2. В строке должны остаться только допустимые символы идентификаторов.
3. Повторяющиеся пробелы должны быть устранены.

---

# Понятие идентификатора

Под идентификатором понимается последовательность символов, состоящая из:

- латинских букв верхнего регистра (`A-Z`);
- латинских букв нижнего регистра (`a-z`);
- цифр (`0-9`);
- символа подчёркивания (`_`).

---

# Проверка символа на принадлежность множеству

Для проверки допустимости символов реализована функция:

```cpp
bool BADElement_Check(char* BME, int size, char element)
````

## Назначение функции

Функция выполняет линейный поиск символа `element` в массиве допустимых символов.

## Возвращаемое значение

| Значение | Описание           |
| -------- | ------------------ |
| `true`   | Символ найден      |
| `false`  | Символ отсутствует |

Функция используется при фильтрации строки от запрещённых символов.

---

# Удаление слов, состоящих только из цифр

Для удаления числовых слов реализована функция:

```cpp
void DellNumbers(string& str)
```

## Алгоритм работы

1. Выполняется последовательный обход строки.
2. Выделяется очередное слово.
3. Проверяется, состоит ли слово исключительно из цифр.
4. Если условие выполняется — слово удаляется методом `erase()`.

После удаления выполняется корректировка индекса, что предотвращает пропуск элементов при изменении длины строки.

---

# Удаление запрещённых символов

Для фильтрации строки используется функция:

```cpp
void DellBadElement(string& str)
```

## Принцип работы

В массиве `masSim` хранится список допустимых символов идентификатора.

Алгоритм обработки:

1. Последовательно перебираются символы строки.
2. Каждый символ проверяется функцией `BADElement_Check()`.
3. Если символ отсутствует в списке допустимых — он удаляется.
4. Если символ допустим — выполняется переход к следующему символу.

## Результат работы

После выполнения функции строка содержит только разрешённые символы идентификаторов.

---

# Удаление повторяющихся пробелов

Для удаления последовательностей пробелов реализована функция:

```cpp
void DellDubleSpace(string& str)
```

## Алгоритм работы

1. Выполняется последовательный просмотр строки.
2. Текущий символ сравнивается с предыдущим.
3. Если обнаружены два подряд идущих пробела — один из них удаляется.

---

# Итог работы программы

В результате обработки:

* удаляются слова, состоящие только из цифр;
* удаляются запрещённые символы;
* устраняются повторяющиеся пробелы;
* строка приводится к формату корректных идентификаторов.
