# Постановка задачи

1. Сформировать одномерный массив целых чисел, используя датчик случайных чисел.  
2. Распечатать полученный массив.  
3. Удалить первый элемент с заданным значением.  
4. Сдвинуть массив циклически на K элементов вправо.  
5. Распечатать полученный массив.  

---

# Анализ задачи

Для решения поставленной задачи требуется использование одномерного динамического массива целых чисел.

---

# 1. Формирование массива

На первом этапе производится создание массива.

Для этого:
- пользователь вводит размер массива `n`;
- выполняется выделение памяти под массив из `n` элементов;
- заполнение массива осуществляется с использованием датчика случайных чисел `rand()` из стандартной библиотеки `<cstdlib>`.

Заполнение массива производится в цикле, при этом каждому элементу массива присваивается случайное целое значение в заданном диапазоне.

---

# 2. Вывод массива на экран

Для вывода элементов массива используется отдельная функция `PrintMass()`.

Функция принимает:
- указатель на массив;
- размер массива `n`.

Вывод осуществляется с помощью цикла, последовательно перебирающего элементы массива по индексам от `0` до `n−1`.

Такой подход обеспечивает универсальность функции и позволяет использовать её для вывода массива на разных этапах работы программы.

---

# 3. Удаление первого элемента с заданным значением

Удаление элемента реализуется в отдельной функции `DellElem()`.

Функция принимает следующие параметры:
- указатель на массив;
- ссылку на размер массива `n`;
- значение элемента, подлежащего удалению.

Алгоритм работы функции заключается в последовательном просмотре элементов массива с целью поиска первого вхождения заданного значения.

После обнаружения элемента:
- все последующие элементы массива сдвигаются на одну позицию влево;
- размер массива уменьшается на единицу.

Если заданное значение в массиве отсутствует, массив остаётся без изменений.

Использование ссылки на размер массива позволяет корректно изменить его значение в вызывающей программе.

---

# 4. Циклический сдвиг массива

Циклический сдвиг массива на `K` элементов вправо выполняется отдельной функцией.

Суть операции заключается в том, что последние `K` элементов массива перемещаются в его начало, при этом относительный порядок элементов сохраняется.

Для корректной работы алгоритма значение `K` приводится по модулю размера массива, что предотвращает избыточные циклы сдвига.

Перемещение элементов выполняется с использованием временных переменных и циклов, без выделения дополнительной памяти под новый массив.

---

# 5. Вывод массива на экран

После выполнения всех операций производится повторный вывод массива на экран с использованием функции `PrintMass()`.

Это позволяет наглядно оценить корректность работы алгоритмов удаления элемента и циклического сдвига.
