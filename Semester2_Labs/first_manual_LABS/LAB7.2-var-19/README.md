# Лабораторная работа  
## Использование функций с переменным числом параметров

---

# 1. Постановка задачи

1. Реализовать функцию, определяющую принадлежность точки с координатами `(x, y)` окружности радиуса `R` с центром в начале координат.

2. Реализовать функцию `belong` с переменным числом параметров, определяющую количество точек, принадлежащих заданной окружности.

3. В функции `main` выполнить не менее трёх вызовов функции `belong` с количеством параметров `3`, `9` и `11`.

4. Вывести результаты работы программы на экран.

---

# 2. Анализ задачи

Для решения поставленной задачи используются арифметические операции, а также механизм передачи переменного числа аргументов из библиотеки `<cstdarg>`.

---

# 2.1 Проверка принадлежности точки окружности

Окружность с центром в начале координат задаётся уравнением:


::contentReference[oaicite:0]{index=0}


Функция `onCircle(int x, int y)` реализует проверку данного условия.

### Алгоритм работы функции

- вычисляется значение `x² + y²`;
- вычисляется значение `R²`;
- производится сравнение;
- если равенство выполняется — функция возвращает `true`, иначе `false`.

Таким образом реализуется строгая проверка принадлежности точки именно окружности, а не кругу.

---

# 2.2 Функция с переменным числом параметров

Функция `belong(int paramCount, ...)` принимает:

- `paramCount` — общее количество переданных аргументов;
- далее список параметров переменной длины.

### Структура передаваемых данных

Первый параметр после `paramCount` — радиус окружности `R`.

Далее параметры передаются попарно:

```text id="paramstruct01"
x1, y1, x2, y2, ...
````

---

### Алгоритм работы функции

1. Проверка корректности числа параметров (`paramCount < 3` — недостаточно данных).
2. Инициализация списка аргументов через `va_list`.
3. Извлечение радиуса окружности.
4. Определение количества точек:

pointCount = \frac{paramCount - 1}{2}

5. В цикле извлекаются координаты точек и для каждой вызывается функция `onCircle`.
6. Если точка принадлежит окружности — счётчик результата увеличивается.
7. После обработки всех аргументов список закрывается вызовом `va_end`.

Функция возвращает количество точек, лежащих на окружности.

---

# 2.3 Вызов функции в `main`

В функции `main` выполняются три вызова `belong`:

* `3` параметра: радиус и одна точка;
* `9` параметров: радиус и четыре точки;
* `11` параметров: радиус и пять точек.

Таким образом демонстрируется корректность работы функции при различном количестве передаваемых данных.

Результаты выводятся на экран с поясняющим текстом.

---

# 3. Текст программы

```cpp id="varargsprog01"
#include <iostream>
#include <cstdarg>
#include <clocale>

const int R = 5;

bool onCircle(int x, int y) {
    return (x * x + y * y == R * R);
}

int belong(int paramCount, ...) {

    if (paramCount < 3)
        return 0;

    va_list args;

    va_start(args, paramCount);

    int result = 0;

    int pointCount = paramCount / 2;

    for (int i = 0; i < pointCount; ++i) {

        int x = va_arg(args, int);
        int y = va_arg(args, int);

        if (onCircle(x, y)) {
            ++result;
        }
    }

    va_end(args);

    return result;
}

int main() {

    setlocale(LC_ALL, "RU");

    int p1 = belong(3, 3, 4);

    std::cout << "Точек на окружности (3 параметра): "
              << p1 << std::endl;

    int p2 = belong(9, 3, 4, 5, 0, -3, 4, 1, 1);

    std::cout << "Точек на окружности (9 параметров): "
              << p2 << std::endl;

    int p3 = belong(11, 3, 4, 5, 0, -3, 4, 0, -5, 2, 2);

    std::cout << "Точек на окружности (11 параметров): "
              << p3 << std::endl;

    return 0;
}
```
