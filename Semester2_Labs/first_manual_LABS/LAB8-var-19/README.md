# Лабораторная работа  
## Работа с двоичными файлами

---

# 1. Постановка задачи

Сформировать двоичный файл из элементов структуры.

Структура содержит следующую информацию о фильме:

1. название;
2. режиссер;
3. страна;
4. приносимая прибыль.

Необходимо:

1. Сформировать двоичный файл из записей структуры.
2. Распечатать содержимое файла.
3. Удалить два элемента из конца файла.
4. Добавить новый элемент после элемента с указанным названием фильма.
5. Для выполнения операций использовать отдельные функции.
6. Предусмотреть сообщения об ошибках при открытии файлов и выполнении операций ввода/вывода.

---

# 2. Анализ задачи

Для решения поставленной задачи используется двоичный файл, содержащий записи структуры `Movie`.

Структура включает следующие поля:

1. `title` — название фильма;
2. `author` — режиссер;
3. `country` — страна производства;
4. `profit` — прибыль фильма.

Работа программы состоит из нескольких этапов.

---

# 2.1 Формирование файла

На первом этапе происходит создание двоичного файла `data.bin`.

Пользователь вводит данные о фильмах.

Каждая запись сохраняется в файл с помощью функции `fwrite()`.

Файл открывается в режиме записи двоичных данных (`"wb"`), что позволяет записывать структуры напрямую в файл.

Каждая запись имеет фиксированный размер, равный:

```cpp
sizeof(Movie)
````

---

# 2.2 Вывод содержимого файла

Для вывода данных используется функция `printFile()`.

### Алгоритм работы функции

1. файл открывается в режиме чтения `"rb"`;
2. производится последовательное чтение записей при помощи функции `fread()`;
3. каждая считанная структура выводится на экран.

Чтение выполняется до тех пор, пока функция `fread()` возвращает успешный результат.

---

# 2.3 Удаление двух последних элементов

Удаление выполняется функцией `deleteLastTwo()`.

### Алгоритм работы

1. файл открывается для чтения;
2. определяется его размер с помощью функций `fseek()` и `ftell()`;
3. вычисляется количество записей в файле;
4. создается временный файл `temp.bin`;
5. в новый файл копируются все записи, кроме последних двух;
6. исходный файл удаляется;
7. временный файл переименовывается в `data.bin`.

Такой подход используется потому, что в двоичных файлах невозможно напрямую удалить запись из середины или конца файла без перезаписи данных.

---

# 2.4 Добавление элемента после указанного

Добавление реализовано функцией `addAfterTitle()`.

### Алгоритм работы

1. пользователь вводит название фильма;
2. создается новая запись структуры;
3. исходный файл открывается для чтения;
4. создается временный файл;
5. записи последовательно копируются из исходного файла;
6. если название текущего фильма совпадает с введенным, после него записывается новый элемент;
7. исходный файл заменяется временным.

Для сравнения строк используется функция `strcmp()` из библиотеки `<cstring>`.

---

# 3. Описание структуры программы

## Структура данных

```cpp
struct Movie
```

Содержит поля для хранения информации о фильме и функции:

1. `input()` — ввод данных;
2. `print()` — вывод данных.

---

## Основные функции программы

### `printFile()`

Функция выводит все записи файла на экран.

---

### `deleteLastTwo()`

Удаляет два последних элемента из файла.

---

### `addAfterTitle()`

Добавляет новую запись после фильма с указанным названием.

---

# 4. Результаты работы программы

В ходе работы программы выполняются следующие действия:

1. Пользователь вводит данные о фильмах.
2. Формируется двоичный файл `data.bin`.
3. Из файла удаляются два последних элемента.
4. Содержимое файла выводится на экран.
5. Пользователь вводит название фильма.
6. После найденного фильма добавляется новая запись.
7. Обновленное содержимое файла снова выводится на экран.
