# Лабораторная работа  
## Перегруженные функции

---

# 1. Постановка задачи

Разработать перегруженные функции и основную программу, которая их вызывает, с целью:

а) для массива целых чисел определить минимальный элемент;

б) для строки определить длину самого короткого слова.

---

# 2. Анализ задачи

Для решения задачи применяются перегруженные функции — одна для массива целых чисел, другая для строки.

---

## 2.1 Минимальный элемент массива

Создаётся массив из десяти элементов:

```cpp
int mass[10]{ 4,5965,2,69,999,89,8,0,1,4 };
````

Функция `Mnn(int* arr, int n)` принимает массив и его размер.

### Алгоритм работы

1. Инициализация переменной минимального значения первым элементом.
2. Цикл перебора элементов массива.
3. Обновление минимального значения при обнаружении меньшего элемента.
4. Возврат минимального элемента.

### Вызов функции

```cpp
cout << "Минимальный элемент массива: " << Mnn(mass, 10) << '\n';
```

---

## 2.2 Длина самого короткого слова в строке

Строковая переменная:

```cpp
string str = "sdf eeeee sdfdf epst s pop aapappap";
```

Функция `Mnn(string s)` принимает строку и возвращает длину самого короткого слова.

### Алгоритм работы

1. Добавление пробела в конец строки.
2. Последовательный проход по символам и подсчёт длины слов.
3. Сравнение длины текущего слова с минимальной и обновление при необходимости.
4. Возврат минимальной длины.

### Вызов функции

```cpp
cout << "Длина самого короткого слова: " << Mnn(str);
```

---

# 3. Основная программа

Основная программа:

* создаёт массив и строку;
* вызывает функции для нахождения минимального элемента массива и длины самого короткого слова;
* выводит результаты на экран.

Перегрузка функций обеспечивает обработку разных типов данных одним именем функции, упрощая код и повышая его читаемость.

---

# 4. Текст программы

```cpp
#include <iostream>
#include <clocale>
#include <string>

using namespace std;

int Mnn(int* arr, int n) { // arr - массив, n - его длина
    int Max = arr[0];

    for (int i = 0; i < n; i++) {
        if (arr[i] > Max) {
            Max = arr[i];
        }
    }

    return Max;
}

int Mnn(string s) {
    s += ' ';

    int i = 0, lenS, minL = s.length();

    while (i != s.length()) {

        lenS = 0;

        while (s[i] != ' ') {
            lenS++;
            i++;
        }

        if (lenS < minL) {
            minL = lenS;
        }

        i++;
    }

    return minL;
}

int main() {

    setlocale(LC_ALL, "RU");

    int mass[10]{ 4,5965,2,69,999,89,8,0,1,4 };

    cout << "Максимальный элемент массива: "
         << Mnn(mass, 10) << '\n';

    string str = "sdf eeeee sdfdf epst s pop aapappap";

    cout << "Длина самого короткого слова: "
         << Mnn(str);

    return 0;
}
```
