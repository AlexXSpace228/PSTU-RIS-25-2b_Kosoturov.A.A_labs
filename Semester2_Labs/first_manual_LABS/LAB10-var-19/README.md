# Лабораторная работа  
## Работа с динамическим массивом строк

---

# 1. Постановка задачи

Написать программу на языке C++, в которой создаётся динамический массив строк, после чего выполняется его обработка.

Необходимо выполнить следующие действия:

1. Сформировать динамический массив строк.
2. Удалить из массива все строки, которые начинаются и заканчиваются на букву `"a"`.
3. Вывести полученный массив строк на экран.

Для реализации задачи необходимо использовать динамическое выделение памяти, а также функции для обработки строковых данных.

---

# 2. Анализ задачи

Для решения поставленной задачи требуется использовать динамический массив строк типа `string`.

Программа должна обеспечить ввод данных пользователем, обработку массива и вывод результата.

---

# 2.1 Формирование массива строк

На первом этапе выполняется создание динамического массива строк.

Пользователь вводит количество элементов массива `N`.

После этого происходит выделение памяти под массив строк с использованием оператора `new`.

Заполнение массива выполняется в отдельной функции `make_array()`.

---

## В функции выполняются следующие действия

1. создаётся динамический массив строк;
2. пользователь последовательно вводит строки;
3. каждая введённая строка сохраняется в соответствующем элементе массива.

Для ввода строк используется функция `getline()`, позволяющая корректно считывать строки, содержащие пробелы.

---

# 2.2 Вывод массива строк

Для вывода элементов массива используется функция `Printarr()`.

Функция принимает два параметра:

1. указатель на массив строк;
2. количество элементов массива.

Вывод выполняется с помощью цикла, который последовательно перебирает все элементы массива и выводит их на экран.

---

# 2.3 Удаление строк из массива

Удаление строк выполняется в функции `Remover()`.

Функция принимает:

1. указатель на исходный массив строк;
2. ссылку на размер массива.

---

## Алгоритм работы функции

Для каждой строки выполняется проверка:

1. строка не должна быть пустой;
2. первый символ строки должен быть `'a'`;
3. последний символ строки также должен быть `'a'`.

Если строка удовлетворяет данным условиям, она подлежит удалению.

---

## Удаление реализуется следующим образом

1. все последующие элементы массива сдвигаются на одну позицию влево;
2. размер массива уменьшается на единицу.

После завершения обработки создаётся новый динамический массив меньшего размера, в который копируются оставшиеся строки.

Исходный массив освобождается с помощью оператора:

```cpp
delete[]
````

---

# 2.4 Вывод результата

После удаления строк формируется новый массив, содержащий только те строки, которые не начинаются и не заканчиваются на букву `"a"`.

Полученный массив выводится на экран с помощью функции `Printarr()`.

Это позволяет визуально проверить корректность выполнения программы.

# 4. Результаты работы программы

1. пользователь вводит строки;

3. выполняется проверка строк;
4. строки, удовлетворяющие условию удаления, исключаются из массива;
5. новый массив выводится на экран.
