# Лабораторная работа  
## Обработка текстовых файлов

---

# 1. Постановка задачи

Дан текстовый файл `F1`.

Необходимо выполнить следующие действия:

1. Скопировать из файла `F1` в файл `F2` все строки, в которых нет слов, совпадающих с первым словом строки.
2. Определить количество согласных букв в первой строке файла `F2`.

Для решения задачи необходимо использовать средства работы с файлами языка C++, а также выполнить обработку строковых данных.

---

# 2. Анализ задачи

Для решения поставленной задачи необходимо выполнить обработку текстовой информации, содержащейся в файле `F1`, а затем записать результат в файл `F2`.

---

# 2.1 Чтение данных из файла

На первом этапе программа открывает входной файл `F1.txt` с использованием класса `ifstream`.

Чтение данных производится построчно с помощью функции `getline()`.

Каждая считанная строка помещается в строковую переменную типа `std::string`.

---

# 2.2 Выделение первого слова строки

После считывания строки необходимо определить первое слово.

Для этого производится последовательный просмотр символов строки до первого пробела.

Каждый символ добавляется во временную строку, в результате чего формируется строка, содержащая первое слово строки.

---

# 2.3 Поиск совпадающих слов

Далее выполняется просмотр оставшейся части строки.

### Алгоритм работы

- последовательно формируются слова строки;
- каждое слово сравнивается с первым словом;
- если обнаруживается совпадение, строка не копируется в файл `F2`.

Если совпадений не найдено, строка записывается в файл `F2`.

Запись производится с использованием объекта `ofstream`.

---

# 2.4 Подсчет согласных букв

После формирования файла `F2` программа повторно открывает его для чтения.

Считывается первая строка файла `F2`.

Далее выполняется подсчет согласных букв.

Для этого используется заранее подготовленный массив `consonants`, содержащий:

- английские согласные буквы (строчные и заглавные);
- русские согласные буквы (строчные и заглавные).

---

## Алгоритм подсчета

1. последовательно просматриваются все символы строки;
2. каждый символ сравнивается со всеми элементами массива согласных букв;
3. если найдено совпадение, счетчик увеличивается на единицу.

Таким образом определяется общее количество согласных букв в первой строке файла `F2`.

---

# 2.5 Вывод результата

В конце работы программы выводятся:

- количество согласных букв в первой строке файла `F2`;
- содержимое файла `F2`.

Это позволяет проверить корректность выполнения программы.
