
# Постановка задачи

1. Для x, изменяющегося от a до b с шагом h = (b−a) / k, где k = 10, вычислить значение функции:

f(x)=e^2x

с использованием разложения в степенной ряд Тейлора.

2. Вычисление выполнить для заданного числа членов ряда n.

3. Для каждого значения x определить точное значение функции.

4. Вывести результаты вычислений в табличной форме для сравнения приближённого и точного значений.

---

# Анализ задачи

Для решения задачи используется разложение экспоненциальной функции в степенной ряд Маклорена.

В программе суммирование выполняется до заданного числа членов ряда n, что обеспечивает приближённое значение функции.

---

# 1. Организация изменения аргумента

Задаются границы интервала:

```text
a = 0
b = 1
````

Количество разбиений:

```text
k = 10
```

Шаг вычисляется по формуле:


h = (b-a)/k


Значение аргумента определяется в цикле по формуле:

[
x<sub>i</sub> = a + i \cdot h,\quad i = 0,1,\dots,k
]

Таким образом формируется 11 точек на заданном интервале.

---

# 2. Вычисление функции через ряд Тейлора

Для вычисления суммы используется отдельная функция:

```cpp
TaylorByN(x, n)
```

Функция принимает:

* значение аргумента x;
* количество членов ряда n.

Алгоритм основан на рекуррентной формуле вычисления очередного члена ряда:

[
a<sub>i</sub> = (a<sub>i-1</sub> 2x) / i
]

Начальное значение:

[
a_0 = 1
]

Такой подход позволяет:

* избежать вычисления факториала;
* снизить количество операций;
* повысить численную устойчивость вычислений.

Суммирование выполняется в цикле от 1 до n, после чего возвращается приближённое значение функции.

---

# 3. Вычисление точного значения функции

Для получения точного значения используется стандартная математическая функция `exp()` из библиотеки `<cmath>`:


f(x)=e^2x


Это позволяет провести сравнение точного и приближённого результата.

---

# 4. Вывод результатов

Вывод организован в табличной форме.

Для каждого значения x отображаются:

* значение аргумента;
* приближённое значение (ряд Тейлора);
* точное значение функции.

Это позволяет визуально оценить точность аппроксимации при фиксированном количестве членов ряда n.
