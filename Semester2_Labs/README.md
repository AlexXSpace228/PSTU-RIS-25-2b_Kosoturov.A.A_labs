# Учебные лабораторные работы

Репозиторий содержит лабораторные работы и учебные проекты, выполненные в рамках изучения программной инженерии, объектно-ориентированного программирования и разработки пользовательских интерфейсов.

---

# Структура репозитория

## OOP_LABS
Лабораторные работы по дисциплине «Объектно-ориентированное программирование».

Основные темы:
- классы и объекты
- конструкторы и деструкторы
- перегрузка операторов
- наследование
- полиморфизм
- STL
- работа с файлами

---

## UI_LABS
Лабораторные работы по разработке пользовательских интерфейсов с использованием Qt.

Основные темы:
- Qt Widgets
- сигналы и слоты
- работа с окнами
- обработка событий
- построение интерфейсов
- работа с формами и элементами управления

---

## FIRST_LABS
Лабораторные работы из первой методички.

Раздел содержит базовые задания, направленные на изучение:
- синтаксиса C++
- базовых алгоритмов
- циклов и условий
- функций
- массивов
- указателей

---

## TASKS_LABS
Отдельные лабораторные и практические задания.

Включает:
- дополнительные задачи
- индивидуальные варианты
- экспериментальные проекты
- самостоятельные работы

---

# Используемые технологии

- C++
- STL
- Qt
- Visual Studio 2022
