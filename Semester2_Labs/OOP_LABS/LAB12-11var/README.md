# Постановка задачи

## Задача 1.

1. Создать ассоциативный контейнер.
2. Заполнить его элементами стандартного типа (тип указан в варианте).
3. Добавить элементы в соответствии с заданием
4. Удалить элементы в соответствии с заданием.
5. Выполнить задание варианта для полученного контейнера.
6. Выполнение всех заданий оформить в виде глобальных функций.

3. Добавить элементы в соответствии с заданием

# Анализ задачи

## Задача 1 (set<double>)

* Создание `set<double>` с начальными значениями `{3.5, 1.2, 7.8, 2.4, 5.1}`.
* Вычисление среднего арифметического элементов (функция `set_average`).
* Добавление среднего арифметического на указанную позицию с сохранением упорядоченности (функция `set_insert_at_pos`: при позиции ≤ 0 вставка в множество, иначе преобразование в вектор, вставка по индексу и обратное заполнение `set`).
* Удаление элементов, ключи которых принадлежат диапазону `[k1, k2]` (функция `set_del_range` через `lower_bound/upper_bound` и `erase`).
* Замена множества новым, в котором каждый элемент увеличен на среднее арифметическое исходного (`set_add_avg`).

---

## Задача 2 (set<idPair>)

* Создание `set<idPair>` с объектами, сконструированными из целой и дробной частей.
* Вычисление среднего арифметического значений объектов `idPair` (функция `idpair_set_average`, возвращает `idPair`).
* Вставка среднего на заданную позицию (`idpair_set_insert_at_pos`) аналогично double-версии.
* Удаление элементов с ключами в диапазоне `[k1, k2]` (`idpair_set_del_range` через `lower_bound/upper_bound`).
* Добавление среднего арифметического к каждому элементу (`idpair_set_add_avg`: вычисление среднего, вызов `sum` для прибавления, новое множество).

---

## Задача 3 (шаблонный класс Container<T> на основе map<int, T>)

* Создание объекта `Container<float>` с начальными значениями `{3.5f, 1.2f, 7.8f, 2.4f, 5.1f}`.
* Метод `Srednee()` – вычисление среднего арифметического всех значений контейнера.
* Метод `Add(pos, val)` – добавление элемента с ключом `pos` (или вставка на позицию, реализовано через `map`).
* Метод `Del(k1, k2)` – удаление элементов с ключами из диапазона `[k1, k2]`.
* Метод `Delenie()` – замена всех значений контейнера на `(значение + среднее арифметическое исходных значений)`.

# Вопросы

1. Ассоциативный контейнер содержит пары значений: ключ и отображенное значение. Зная ключ, можно получить доступ к значению.

2. `map`, `multimap`, `set`, `multiset`, `bitset`.

3. С помощью операции индексации `[]` (для `map`) или через итераторы (`begin`, `end`, `rbegin`, `rend`). Для `multimap` и `multiset` – только через итераторы.

4. `insert`, `erase`, `clear`, `find`, `count`, `lower_bound`, `upper_bound`, `key_comp`, `value_comp`, `swap`, `empty`, `size`, `max_size`.

5. `map<int, float> m1; map<int, string> m2; map<int, Time> m3;` также можно с инициализацией диапазоном или копированием.

6. По умолчанию упорядочены по возрастанию ключа с помощью `less<Key>`. Для обратного порядка нужно указать `greater<Key>`: `map<int, T, greater<int>>`.

7. Операции: `==, !=, <, <=, >, >=`, оператор присваивания, оператор индексации `[]`, методы `insert`, `erase`, `clear`, `find`, `count`, `lower_bound`, `upper_bound`, `size`, `empty`, `swap`.

8.

```cpp
void add(map<int, T> &m, int key, T val) {
    m.insert(make_pair(key, val));
}
```

9.

```cpp
void add(map<int, T> &m, int key, T val) {
    m[key] = val;
}
```

10.

```cpp
void print(map<int, T> &m) {
    for (auto it = m.begin(); it != m.end(); ++it)
        cout << it->first << " : " << it->second << endl;
}
```

11.

```cpp
void print(map<int, T> &m) {
    for (int i = 0; i < m.size(); ++i)
        cout << i << " : " << m[i] << endl;
}
```

(но это работает только если ключи целые и идут подряд, в общем случае – неверно).

12. `map` хранит уникальные ключи, `multimap` допускает дубликаты. Для `multimap` не определена операция `[]`.

13. `set` – ассоциативный контейнер, хранящий только ключи (без отдельных значений), упорядоченные по возрастанию. Элементы уникальны.

14. `map` хранит пары (ключ, значение), `set` хранит только ключи. В `map` ключ и значение могут быть разного типа, в `set` тип один.

15. `set<int> s1; set<int> s2(a, a+5); set<int> s3(s2);` где `a` – массив.

16. По умолчанию по возрастанию (`less<T>`). Для обратного порядка: `set<T, greater<T>>`.

17. Операции сравнения (`==, !=, <, >, <=, >=`), присваивание, `insert`, `erase`, `clear`, `find`, `count`, `lower_bound`, `upper_bound`, `size`, `empty`, `swap`, `key_comp`, `value_comp`.

18.

```cpp
void add(set<T> &s, T val) {
    s.insert(val);
}
```

19.

```cpp
void print(set<T> &s) {
    for (auto it = s.begin(); it != s.end(); ++it)
        cout << *it << " ";
}
```

20. `set` хранит уникальные ключи, `multiset` допускает дубликаты. Для `multiset` метод `count()` может вернуть число больше 1, а `find()` возвращает первый найденный.
