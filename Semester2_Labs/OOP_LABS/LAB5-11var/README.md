# Постановка задачи

1. Определить абстрактный класс.  
2. Определить иерархию классов, в основе которой будет находиться абстрактный класс (см. лабораторную работу №4).  
3. Определить класс Вектор, элементами которого будут указатели на объекты иерархии классов.  
4. Перегрузить для класса Вектор операцию вывода объектов с помощью потоков.  
5. В основной функции продемонстрировать перегруженные операции и полиморфизм Вектора.

# Описание классов и их компонентных функций

Я разбил программу на несколько файлов, чтобы код не лежал в одной куче. У меня получилось три класса:

- **Класс TRIAD (абстрактный)**  
  Это основа. В нем лежат три защищенных (protected) поля типа int: first, second, third. Я написал для них стандартные штуки: конструкторы (с параметрами, по умолчанию, копирования), геттеры и сеттеры. Еще перегрузил операторы присваивания, ввода >> и вывода << (он выводит числа через черточку |). Главная фишка этого класса — три чисто виртуальных метода: plus_first_one(), plus_second_one(), plus_third_one(). Из-за них класс и стал абстрактным (объект такого класса напрямую создать нельзя).

- **Класс TIME (производный от TRIAD)**  
  Он наследует все поля базового класса, но мы договариваемся, что first — это часы, second — минуты, third — секунды. Тут я реализовал те самые виртуальные методы: например, когда мы делаем plus_third_one() (плюс 1 секунда), метод проверяет — если секунд стало 60, он их обнуляет и вызывает plus_second_one() (прибавляет минуту). Аналогично для минут и часов (часы сбрасываются после 24). Также я добавил методы plusHOURS, plusMINUTES и plusSECONDS, чтобы можно было прибавить сразу много времени, и перегрузил оператор << специально для TIME, чтобы время выводилось красиво с ведущими нулями (через std::setfill('0')), типа 23:05:09.

- **Класс Vector**  
  Это класс-контейнер. В нем лежит динамический массив указателей на базовый класс TRIAD** arr и его размер size. В нем есть методы set (чтобы положить объект в ячейку) и get (чтобы достать). И самое удобное — перегруженный вывод <<, который просто циклом пробегается по массиву и печатает каждый элемент. В деструкторе я аккуратно чищу память, чтобы не было утечек.

# Функция main() и глобальные функции

Из глобального у меня только перегруженные операторы ввода-вывода (они объявлены как friend). В main() я делаю следующее:

1. Создаю Vector на 3 элемента.  
2. Кладу туда три разных объекта времени (new TIME(...)).  
3. Печатаю их — выводится исходное время.  
4. В цикле через указатели базового класса вызываю метод plus_third_one(). И тут срабатывает полиморфизм! Вызывается метод не из TRIAD, а переопределенный метод из TIME. Всем прибавляется по 1 секунде.  
5. Потом я беру второй и первый элементы и прибавляю к ним 125 секунд и 61 минуту соответственно. Так как методы plusSECONDS и plusMINUTES есть только в классе TIME, а вектор возвращает указатель типа TRIAD*, мне пришлось использовать dynamic_cast<TIME*>, чтобы привести указатель к нужному типу и вызвать эти функции.

# Объяснение результатов работы программы

При запуске программы в консоль выводится следующее:

Исходные значения:  
23:59:58 10:20:30 05:59:59  

Увеличиваем каждое время на 1 секунду:  
23:59:59 10:20:31 06:00:00  

(тут видно, что 59 секунд и 59 минут переполнились и час корректно увеличился)

Добавим 125 секунд ко второму элементу:  
23:59:59 10:22:36 06:00:00  

(125 секунд — это 2 минуты и 5 секунд, так что к 10:20:31 прибавилось как надо)

Добавим 61 минуту к первому элементу:  
01:00:59 10:22:36 06:00:00  

(61 минута = 1 час и 1 минута. Время 23:59 перевалило за полночь и стало 01:00)

Все методы, включая переполнение времени и переход через сутки, работают правильно.

# Ответы на контрольные вопросы

1. **Какой метод называется чисто виртуальным? Чем он отличается от виртуального метода?**  
Чисто виртуальный метод — это метод без реализации в базовом классе, объявляется как `virtual void func() = 0;`. В отличие от обычного виртуального метода, реализация полностью переносится в наследники.

2. **Какой класс называется абстрактным?**  
Класс, содержащий хотя бы один чисто виртуальный метод. Объекты такого класса создавать нельзя.

3. **Для чего предназначены абстрактные классы?**  
Для задания общего интерфейса и структуры для иерархии классов. Используются как шаблон поведения для наследников.

4. **Что такое полиморфные функции?**  
Это виртуальные функции, поведение которых зависит от реального типа объекта при вызове через базовый указатель/ссылку.

5. **Чем полиморфизм отличается от принципа подстановки?**  
Подстановка — возможность использовать объект наследника вместо базового. Полиморфизм — механизм, который обеспечивает корректный выбор метода в runtime.

6. **Привести примеры иерархий с использованием абстрактных классов.**  
Например:  
- Транспортное_средство → Автомобиль, Велосипед, Лодка (метод ехать())  
- Фигура → Квадрат, Круг (метод найти_площадь())

7. **Привести примеры полиморфных функций.**  
plus_first_one(), plus_second_one(), plus_third_one().  
В геометрии: найти_площадь().

8. **В каких случаях используется механизм позднего связывания?**  
При вызове виртуальных функций через указатели или ссылки на базовый класс. Решение о вызове конкретной реализации принимается во время выполнения программы (runtime).
