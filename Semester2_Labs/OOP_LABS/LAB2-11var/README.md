# 2. Контрольные вопросы (ответы)

## 1. Для чего нужен конструктор?
Конструктор предназначен для инициализации объекта. Он вызывается автоматически при создании объекта и позволяет избежать ошибок, связанных с использованием неинициализированных переменных.

## 2. Сколько типов конструкторов существует в С++?
Существует три основных типа: конструктор с параметрами, конструктор без параметров и конструктор копирования.

## 3. Для чего используется деструктор? В каких случаях деструктор описывается явно?
Деструктор применяется для освобождения ресурсов, выделенных объекту (например, динамической памяти). Явное описание требуется, если объект содержит указатели на память, выделенную динамически (через new), чтобы избежать утечек памяти.

## 4. Для чего используется конструктор без параметров? Конструктор с параметрами? Конструктор копирования?
1. Без параметров: для создания «пустого» объекта или объекта со значениями по умолчанию.  
2. С параметрами: для инициализации объекта конкретными требуемыми значениями.  
3. Копирования: для создания нового объекта, который является точной копией уже существующего.

## 5. В каких случаях вызывается конструктор копирования?
Он вызывается в трех случаях: при инициализации нового объекта другим объектом, при передаче объекта в функцию по значению и при возврате объекта из функции.

## 6. Перечислить свойства конструкторов.
Конструктор совпадает по имени с классом, не возвращает значения, может быть перегружен, не наследуется, не может быть const, virtual или static, вызывается автоматически.

## 7. Перечислить свойства деструкторов.
Имя начинается с тильды (~), не имеет аргументов и возвращаемого значения, не наследуется, может быть виртуальным, вызывается автоматически при удалении объекта из памяти.

## 8. К каким атрибутам имеют доступ методы класса?
Методы имеют неограниченный доступ ко всем элементам класса (включая private), независимо от спецификаторов доступа.

## 9. Что представляет собой указатель this?
Это неявный указатель на тот объект, для которого вызван метод. Он используется для доступа к полям текущего объекта или для возврата ссылки на него.

## 10. Какая разница между методами, определенными внутри класса и вне класса?
Метод внутри класса по умолчанию считается встроенным (inline). При определении вне класса в самом классе остается только прототип, а реализация выносится с использованием оператора ::.

## 11. Какое значение возвращает конструктор?
Конструктор не возвращает никакого значения, даже типа void.

## 12. Какие методы создаются по умолчанию?
Компилятор автоматически создает конструктор без параметров (если не указаны другие), конструктор копирования и деструктор.

## 13. Какое значение возвращает деструктор?
Деструктор не возвращает значения.

## 14. Какой метод отсутствует в описании класса Student?
Отсутствует конструктор без параметров (по умолчанию), так как при наличии конструктора с параметрами он автоматически не создается. Также отсутствует метод для вывода данных (например, show).

## 15. Какой метод будет вызван: student* s; s = new student;?
Будет вызван конструктор без параметров (по умолчанию).

## 16. Какой метод будет вызван: student s(“Ivanov”, 20);?
Будет вызван конструктор с параметрами.

## 17. Какие методы будут вызваны: student s1(“Ivanov”, 20); student s2 = s1;?
Для s1 — конструктор с параметрами, для s2 — конструктор копирования.

## 18. Какие методы будут вызваны: student s1(“Ivanov”, 20); student s2; s2 = s1;?
Для s1 — конструктор с параметрами, для s2 — конструктор без параметров. При s2 = s1 вызывается оператор присваивания (не конструктор).

## 19. Какой конструктор будет использоваться при передаче параметра в функцию print(student a)?
Будет использован конструктор копирования.

## 20. Каким образом можно присвоить новое значение атрибуту name объекта p?
С помощью метода-модификатора: p.set_name("Новое имя");

## 3.2 Описание класса (Class_Automobile.h)

Класс AUTOMOBILE инкапсулирует данные об автомобиле: марку (mark), модель (model) и стоимость (cost). Доступ к полям ограничен (private), взаимодействие происходит через публичные методы.

---

## 3.3 Определение компонентных функций

В классе реализованы:
- Модификаторы (сеттеры): setmark, setmodel, setcost для изменения значений полей.
- Селекторы (геттеры): getmark, getmodel, getcost для чтения значений.
- Метод show(): выводит информацию об объекте в консоль.

---

## 3.4 Определение функций make_auto() и print_auto()

- make_auto(): создает объект внутри функции, запрашивая данные у пользователя, и возвращает его. Это демонстрирует вызов конструктора копирования при возврате значения.
- print_auto(AUTOMOBILE a): принимает объект по значению, что демонстрирует вызов конструктора копирования при передаче аргумента.

---

## 3.5 Объяснение результатов работы программы

При запуске программы в консоли последовательно отображаются:

1. Создание a1 конструктором без параметров (значения "Default", 0).
2. Создание a2 конструктором с параметрами ("Toyota", "Camry", 3000000).
3. Создание a3 путем копирования a2. Изменение a3 через сеттеры не влияет на a2.
4. Передача a3 в print_auto вызывает копирование объекта.
5. Вызов make_auto создает объект и копирует его результат в a1.
