# 1. Постановка задачи

## 1. Общая постановка задачи:
Реализовать определение нового класса (или структуры-пары с полями first и second). Написать главную функцию для демонстрации работы с объектами. Продемонстрировать различные способы создания объектов (статические, динамические) и массивов объектов. Реализовать методы Init() (с контролем значений), Read() (ввод с клавиатуры), Show() (вывод на экран). Реализовать внешнюю функцию make_тип(), которая возвращает структуру как результат или завершает работу при ошибочных параметрах.

## 2. Конкретный вариант (согласно вашему коду):
Реализовать класс A, где поле first (тип double) обозначает базовый оклад сотрудника, а поле second (тип int) — количество отработанных дней. Дополнительно реализовать метод summa(int day_in_month), который вычисляет фактическую заработную плату (оклад, разделенный на количество дней в месяце и умноженный на количество отработанных дней).

A.

# 3. Определение компонентных функций

## 1. Init(double f, int s):
метод инициализации. Проверяет переданные параметры (оклад и количество дней не могут быть отрицательными). Если данные корректны, присваивает их полям first и second и возвращает true. В противном случае возвращает false.

## 2. Read():
метод интерактивного ввода. В цикле do-while запрашивает у пользователя ввод значений оклада и дней. Цикл продолжается до тех пор, пока метод Init() не вернет true (то есть пока не будут введены корректные неотрицательные значения).

## 3. Show():
константный метод для форматированного вывода значений полей first и second в консоль.

## 4. summa(int day_in_month):
константный метод, принимающий количество дней в текущем месяце. Возвращает рассчитанную сумму по формуле: (first / day_in_month) * second. Предусмотрена защита от деления на ноль.

Если параметры валидны, функция возвращает созданный объект.

# 6. Ответы на контрольные вопросы

## 1. Что такое класс?
Класс — это пользовательский тип данных, который объединяет в себе данные (поля/атрибуты) и функции для работы с этими данными (методы). Он является своеобразным чертежом для создания объектов.

## 2. Что такое объект (экземпляр) класса?
Объект — это конкретная переменная, созданная на основе класса. Он обладает состоянием (значениями полей) и поведением (методами), описанными в классе.

## 3. Как называются поля класса?
Поля класса называются атрибутами или переменными-членами (data members).

## 4. Как называются функции класса?
Функции класса называются методами или функциями-членами (member functions).

## 5. Для чего используются спецификаторы доступа?
Спецификаторы доступа используются для реализации инкапсуляции — сокрытия внутреннего устройства класса и контроля доступа к его полям и методам извне.

## 6. Для чего используется спецификатор public?
Спецификатор public (открытый) делает поля и методы доступными из любой точки программы, где доступен сам объект.

## 7. Для чего используется спецификатор private?
Спецификатор private (закрытый) ограничивает доступ: к таким полям и методам можно обращаться только изнутри методов самого этого класса.

## 8. Если описание класса начинается со спецификатора class, то какой спецификатор доступа будет использоваться по умолчанию?
По умолчанию в class используется спецификатор private.

## 9. Если описание класса начинается со спецификатора struct, то какой спецификатор доступа будет использоваться по умолчанию?
По умолчанию в struct используется спецификатор public.

## 10. Какой спецификатор доступа должен использоваться при описании интерфейса класса? Почему?
Для интерфейса (методов, с которыми будет взаимодействовать остальная программа) должен использоваться спецификатор public. Это позволяет внешнему коду использовать функционал объекта, не вмешиваясь в его внутреннее (скрытое) состояние.

## 11. Каким образом можно изменить значения атрибутов экземпляра класса?
Если атрибут public, его можно изменить напрямую (например, obj.field = value). Если атрибут private (как принято правилами хорошего тона), его изменяют через специальные публичные методы (сеттеры) или функции инициализации (например, ваш метод Init()).

## 12. Каким образом можно получить значения атрибутов экземпляра класса?
Аналогично: напрямую, если они public, или через публичные методы (геттеры/методы вывода вроде Show()), если они private.

## 13. Как можно обратиться к полю name объекта s (struct, динамический)?
Для указателя на объект структуры обращение происходит через оператор стрелки: s->name.

## 14. Как можно обратиться к полю name объекта s (struct, статический)?
Для обычного объекта структуры обращение происходит через оператор точку: s.name.

## 15. Как можно обратиться к полю name объекта s (class, динамический, без спецификатора)?
Напрямую обратиться нельзя, так как по умолчанию в class поля являются private. Обращение вызовет ошибку компиляции. Доступ возможен только если добавить публичный метод-геттер (например, s->getName()).

## 16. Как можно обратиться к полю name объекта s (class, статический, поле до public)?
Напрямую обратиться нельзя, так как поле объявлено до спецификатора public, а значит, оно является private.

## 17. Как можно обратиться к полю name объекта s (class, динамический, после public)?
Так как поле находится в секции public, к нему можно обратиться через указатель с помощью оператора стрелки: s->name.
