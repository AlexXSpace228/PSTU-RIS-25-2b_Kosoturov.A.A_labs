# Лабораторная работа: Класс A (C++)

## 1. Постановка задачи

### 1.1 Общая постановка задачи
Реализовать определение нового класса (или структуры-пары с полями `first` и `second`).  
Написать главную функцию для демонстрации работы с объектами.

Требуется:
- продемонстрировать различные способы создания объектов (статические и динамические)
- создать массивы объектов
- реализовать методы:
  - `Init()` — с контролем значений
  - `Read()` — ввод с клавиатуры
  - `Show()` — вывод на экран
- реализовать внешнюю функцию `make_тип()`, которая:
  - возвращает структуру/объект
  - либо завершает программу при ошибочных параметрах

---

### 1.2 Конкретный вариант

Реализовать класс `A`, где:

- `first (double)` — базовый оклад сотрудника
- `second (int)` — количество отработанных дней

Дополнительно:
- метод `summa(int day_in_month)` — вычисляет заработную плату:

\[
\text{salary} = \left(\frac{first}{day\_in\_month}\right) \cdot second
\]

---

## 2. Описание класса

### 2.1 Имя класса
`A`

---

### 2.2 Поля класса (private)

- `double first` — базовый оклад  
- `int second` — количество отработанных дней  

---

### 2.3 Методы (public)

- конструктор по умолчанию
- `Init()`
- `Read()`
- `Show()`
- `summa()`

---

## 3. Определение компонентных функций

### 3.1 Init(double f, int s)

Инициализация объекта.

Проверки:
- `f >= 0`
- `s >= 0`

Результат:
- `true` — если данные корректны
- `false` — если данные некорректны

---

### 3.2 Read()

Метод ввода данных с клавиатуры.

Особенности:
- цикл `do-while`
- повторяется до тех пор, пока `Init()` не вернет `true`

---

### 3.3 Show()

Константный метод вывода:
- `first`
- `second`

---

### 3.4 summa(int day_in_month)

Константный метод расчёта зарплаты:

\[
(first / day\_in\_month) \cdot second
\]

Особенности:
- защита от деления на 0

---

## 4. Функция make_A()

### 4.1 Назначение

Внешняя функция (не метод класса), создающая объект `A`.

---

### 4.2 Логика работы

1. создаётся временный объект `obj`
2. вызывается `obj.Init(f, s)`
3. если данные неверны:
   - выводится ошибка
   - вызывается `exit(1)`
4. если данные корректны:
   - возвращается объект

---

## 5. Объяснение работы программы

1. Создаются объекты разными способами:
   - `something1` — локальный объект
   - `something2` — динамический объект (указатель)
   - `std::vector<A>` — динамический массив

2. `something1` инициализируется через:
   - `make_A(50000.0, 15)`

3. `something2` заполняется через:
   - ввод с клавиатуры (`Read()`)

4. Выводятся:
   - данные первых двух объектов
   - их зарплата при 30 днях в месяце

5. Пользователь задаёт размер массива `LEN`

6. Вектор заполняется через `Read()`

7. Финальный цикл:
   - `Show()` для каждого элемента
   - расчёт зарплаты

## 6. Контрольные вопросы

### 1. Что такое класс?
Класс — пользовательский тип данных, объединяющий:
- поля (данные)
- методы (функции обработки)

---

### 2. Что такое объект?
Объект — экземпляр класса с конкретными значениями полей и доступными методами.

---

### 3. Как называются поля класса?
Атрибуты или переменные-члены (data members).

---

### 4. Как называются функции класса?
Методы или member functions.

---

### 5. Для чего нужны спецификаторы доступа?
Для реализации инкапсуляции и ограничения доступа к данным.

---

### 6. Что делает `public`?
Делает элементы доступными извне класса.

---

### 7. Что делает `private`?
Ограничивает доступ только внутри класса.

---

### 8. `class` по умолчанию?
`private`

---

### 9. `struct` по умолчанию?
`public`

---

### 10. Какой доступ для интерфейса класса?
`public`, чтобы обеспечить использование извне.

---

### 11. Как изменить атрибуты объекта?
- напрямую (если `public`)
- через методы (`Init`, сеттеры)

---

### 12. Как получить значения атрибутов?
- напрямую (если `public`)
- через методы (`Show`, геттеры)

---
