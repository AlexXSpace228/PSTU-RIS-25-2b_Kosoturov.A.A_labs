# Постановка задачи

1. Реализовать класс, перегрузить для него операции, указанные в варианте.  
2. Определить исключительные ситуации.  
3. Предусмотреть генерацию исключительных ситуаций.  

---

Целью данной работы является проектирование и реализация защищенного контейнерного класса «СПИСОК» (целочисленный тип int). Основной акцент сделан на использовании механизма исключений для предотвращения аварийного завершения программы при логических ошибках или некорректном вводе.

В соответствии с 11-м вариантом, необходимо реализовать следующие перегруженные операции:

- Операция `[]`: доступ к элементу по индексу.  
- Оператор приведения типа `int()`: возвращает текущее количество узлов в списке.  
- Бинарный оператор `+`: выполняет сложение двух списков (создается новый список, где $c[i] = a[i] + b[i]$).  
- Унарная операция `- n`: переход «влево» от хвоста списка к элементу, стоящему на позиции $n$ с конца.

# Словесное описание исключительных ситуаций

Для обеспечения отказоустойчивости в классе выделены три типа критических ситуаций:

1. **IndexError1 (Отрицательное значение):**  
   Срабатывает, если при инициализации или доступе передается индекс $i < 0$.

2. **IndexError2 (Выход за верхнюю границу):**  
   Генерируется, если запрашиваемый индекс больше или равен текущему значению `size`.

3. **ListSizeMismatch (Несоответствие длин):**  
   Специфическая ошибка для оператора `+`. Сложение двух списков возможно только при равенстве их размеров.

# Проектирование иерархии исключений

Иерархия построена по принципу «от общего к частному».

| Класс исключения | Описание | Сообщение (what) |
|------------------|----------|------------------|
| Error | Базовый виртуальный класс | "Unknown Error" |
| IndexError | Ошибки позиционирования | "Index Range Error" |
| IndexError1 | Отрицательный индекс | "Index Error: Value is negative!" |
| IndexError2 | Выход за границы | "Index Error: Out of bounds!" |
| SizeError | Ошибки размеров | "Size Logic Error" |
| ListSizeMismatch | Несовпадение размеров | "Size Error: Lists have different sizes!" |

---

# Реализация класса-контейнера

Для реализации операции `- n` (смещение от конца списка) контейнер спроектирован как **двусвязный список**.

- **Структура Node:** содержит `int data`, а также указатели `*next` и `*prev`.  
- **Механика `- n`:** благодаря указателю `tail` и полю `prev` можно начинать обход с конца списка без прохода от головы.  
- **Управление памятью:** деструктор проходит по всем узлам и освобождает память, предотвращая утечки.

# Программный код (фрагменты)

## Описание класса List

```cpp
struct Node {
    int data;
    Node *next, *prev;
    Node(int d, Node* n = nullptr, Node* p = nullptr)
        : data(d), next(n), prev(p) {}
};

class List {
    int size;
    Node *head, *tail;

public:
    List(int s); // с проверкой IndexError1
    int& operator[](int i); // IndexError1 и IndexError2
    List operator+(const List& other); // ListSizeMismatch
    int& operator-(int n); // доступ от хвоста
    operator int() const { return size; } // приведение типа
};
````

# Ответы на контрольные вопросы

1. **Что такое исключение?**
   Механизм обработки ошибок времени выполнения с передачей управления в блок обработки.

2. **Разделение процесса:**
   Разделяет обнаружение ошибки (`throw`) и обработку (`catch`).

3. **Оператор генерации:**
   `throw`.

4. **Try-блок:**
   Контролируемый блок, в котором отслеживаются исключения.

5. **Catch-блок:**
   Блок обработки конкретного типа исключений.

6. **Формы catch:**
   По значению, по ссылке (рекомендуется), `catch(...)`.

7. **Базовый класс:**
   `std::exception`.

8. **Иерархия исключений:**
   Строится через наследование.

9. **throw(int, double):**
   Старая спецификация допустимых исключений.

10. **throw():**
    Гарантия отсутствия исключений (аналог `noexcept`).

11. **Место генерации:**
    Внутри `try` или вызываемых функций.

12. **Формула Герона (площадь треугольника):**
    p = (a+b+c) / 2
    S = sqrt(p(p-a)(p-b)(p-c))
