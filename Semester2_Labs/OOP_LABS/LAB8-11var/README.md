# Общая задача

- Создать абстрактный базовый класс с виртуальными методами.  
- Реализовать контейнер (группу) для хранения объектов разных типов.  
- Разработать систему обработки событий (сообщений) для взаимодействия пользователя с программой через класс-диспетчер.

# Специфика варианта №11

- Базовый класс: **Person (Человек)**  
  Атрибуты: имя (`string`), возраст (`int`)  

- Производный класс: **Student (Студент)**  
  Дополнительный атрибут: рейтинг (`float`)  

- Контейнер: бинарное дерево (**Tree**)  

- Команды управления:  
  - `m N` — создание группы из N элементов  
  - `+` — добавление нового объекта  
  - `-` — полная очистка дерева  
  - `s` — просмотр всей группы  
  - `?N` — поиск и вывод объекта по идентификатору N  
  - `q` — выход из программы

# Описание класса-контейнера

Для хранения данных используется класс **Tree**. Контейнер построен на основе динамических узлов **Node**, каждый из которых содержит указатель на базовый тип `Object*`, что позволяет реализовать полиморфное хранение объектов **Person** и **Student**.

Класс Tree инкапсулирует:

- корень дерева (`root`)  
- текущий размер  
- счетчик для генерации уникальных ID  

Основное преимущество использования дерева — иерархическое представление данных, где добавление и поиск реализуются через рекурсивные алгоритмы.

# Определение компонентных функций

Выделяются следующие ключевые функции:

- **HandleEvent(const TEvent& e):**  
  Метод обработки событий. В `Person` и `Student` отвечает за реакцию на команду отображения объекта. В `Dialog` распределяет команды между функциями дерева.

- **Input() и Show():**  
  Чисто виртуальные методы базового класса `Object`, переопределяются в наследниках для ввода/вывода специфических полей (например, рейтинга студента).

- **Insert(Node* t, Object* obj):**  
  Рекурсивная вставка элемента. В упрощенной реализации добавление идет в левую ветку дерева.

- **Find(Node* t, int id):**  
  Рекурсивный поиск объекта по идентификатору.

- **Clear(Node* t):**  
  Рекурсивное освобождение памяти узлов и объектов.

# Описание процесса итерации

Классический итератор не выделен отдельно. Его функции выполняют рекурсивные обходы дерева, например `Print(Node* t)`.

Итерация по группе реализуется через:

- обход узлов от корня  
- вызов виртуальных методов объектов  
- полиморфное выполнение `Show()`  

Это обеспечивает независимость обхода от конкретного типа объекта.

---

# Функция main()

Главная функция инициализирует локаль и создает объект класса `Dialog`.

Основная логика находится в методе `Execute()`, который запускает цикл обработки событий.

```cpp
int main() {
    setlocale(LC_ALL, "ru");
    Dialog d;
    d.Execute();
    return 0;
}
````

Программа завершается только после получения события `cmQuit`.

# Объяснение результатов работы

При запуске отображается меню команд. Пользователь может:

* создавать объекты группами или по одному
* добавлять элементы
* выполнять поиск
* просматривать дерево

Команда вида `?2` преобразуется в структуру `TEvent` с параметром 2.
Далее система:

1. выполняет поиск узла
2. вызывает `Show()` у найденного объекта

Использование `union` в структуре события позволяет эффективно передавать как код команды, так и параметры.

# Ответы на контрольные вопросы

1. **Класс-группа** — объект, объединяющий другие объекты. Примеры: окно с кнопками, факультет со студентами.

2. **Описание List:**
   `class List { Node* head; public: void Add(); void Del(); };`

3. **Конструкторы List:**
   `List()`, `List(int n)`, `List(const List& l)`

4. **Деструктор List:**
   Удаление через цикл `while(head)` с освобождением памяти узлов.

5. **Просмотр List:**
   Обход списка с вызовом `Show()` для каждого элемента.

6. **Вид иерархии:**
   Агрегация или композиция (целое-часть).

7. **Абстрактный класс во главе:**
   Необходим для полиморфизма и единого интерфейса работы с объектами.

8. **Событие:**
   Информационный пакет о действии пользователя или системы.

9. **Характеристики события:**
   Код типа, команда, параметры.

10. **Структура события:**
    `struct TEvent { int what; int command; };`

11. **Поле what:**
    Тип события: `evNothing`, `evMessage`, системные коды.

12. **Поле command:**
    Код операции (например `cmAdd`, `cmQuit`).

13. **Поля a и message:**
    `a` — параметр команды, `message` — тип сообщения.

14. **Методы:**
    `GetEvent`, `Execute`, `HandleEvent`, `ClearEvent`.

15. **Главный цикл:**
    `do { GetEvent(e); HandleEvent(e); } while (!Valid());`

16. **ClearEvent():**
    Сбрасывает `what = evNothing`.

17. **HandleEvent():**
    Обработка через `switch-case` по коду события.

18. **GetEvent():**
    Чтение ввода пользователя и формирование `TEvent`.

19. **EndState:**
    Флаг завершения работы (0 — работа, 1 — выход).

20. **Valid():**
    Проверка возможности продолжения цикла.
