# Общая задача

Нам необходимо было разработать собственный абстрактный тип данных — класс-контейнер, а также реализовать для него итератор. Нужно было написать конструкторы, деструктор, перегрузить операции ввода-вывода и присваивания.

Задача моего варианта: создать контейнер «ОДНОНАПРАВЛЕННЫЙ СПИСОК», который хранит целые числа (int). Дополнительно нужно было перегрузить специфические операции:

1. `[]` — доступ к элементу по индексу;  
2. `int()` — приведение типа для получения текущего размера списка;  
3. `+` — поэлементное сложение двух списков (то есть `c[i] = a[i] + b[i]`);  
4. `-` — операция перехода к элементу с заданным номером с использованием разработанного класса-итератора.

# Описание класса-контейнера и компонентных функций

В качестве основы я использовал структуру **Node**, которая представляет собой узел однонаправленного списка. Узел хранит само значение (value) и указатель на следующий элемент (next).

Сам класс **LIST** содержит два приватных поля:

1. `head` — указатель на начало списка;  
2. `size` — счетчик количества элементов (чтобы каждый раз не пересчитывать их в цикле).  

## Основные реализованные функции (компоненты класса)

1. **Конструктор LIST(int s, int k):**  
   Создает список заданного размера `s` и заполняет его значением `k`. Реализован через цикл с использованием вспомогательного метода `pushback`.

2. **Конструктор копирования и оператор =:**  
   Необходимы для предотвращения поверхностного копирования указателей. При присваивании старые данные удаляются, новые копируются поэлементно.

3. **Деструктор ~LIST():**  
   Проходит по всему списку через `while (head)` и освобождает память каждого узла с помощью `delete`.

4. **Оператор []:**  
   Так как это список, доступ по индексу имеет сложность O(n). Происходит проход от начала списка до нужного индекса. Возвращается `int&`, что позволяет изменять элементы (`a[2] = 100`).

5. **Оператор приведения типа operator int():**  
   Возвращает поле `size`.

6. **Оператор сложения +:**  
   Проверяет равенство размеров списков. Если размеры не совпадают — выбрасывается `std::length_error`.  
   При совпадении создается новый список с поэлементным сложением значений.

7. **Перегрузка потоков << и >>:**  
   Обеспечивает ввод и вывод списка через стандартные потоки.

# Описание класса-итератора

Для эффективного обхода списка реализован класс **Iterator**, представляющий собой упрощенный «умный указатель» на узел.

Внутри хранится:

- `current` — указатель на текущий узел.

## Перегруженные операции:

1. `*` — разыменование (возвращает значение текущего узла);  
2. `++` — переход к следующему элементу (`current = current->next`);  
3. `!=` — проверка окончания обхода.  

В классе LIST добавлены:

- `begin()` — возвращает итератор на `head`;  
- `end()` — возвращает итератор на `nullptr`;  
- оператор `-` — сдвиг итератора на n элементов вперед от начала списка.

# Ответы на контрольные вопросы

## 1. Что такое абстрактный тип данных? Примеры АТД

АТД — это модель данных, которая описывает структуру и набор операций, скрывая реализацию.
Примеры: стек, очередь, список, дерево.

## 2. Абстракция через параметризацию

Реализуется через шаблоны (templates) C++.
Пример: `std::vector<int>`, `std::vector<double>`.

## 3. Абстракция через спецификацию

Разделение интерфейса и реализации.
Пример: `.h` и `.cpp` файлы.

## 4. Что такое контейнер? Примеры

Контейнер — структура для хранения набора объектов.
Примеры: `std::vector`, `std::list`, `std::map`, `std::set`.

## 5. Группы операций контейнеров

* конструкторы/деструкторы
* доступ к элементам
* вставка/удаление
* информация о контейнере
* работа с итераторами

## 6. Виды доступа к элементам

* произвольный (O(1)) — массив, vector
* последовательный (O(n)) — list, файлы

## 7. Что такое итератор

Объект для последовательного обхода контейнера без раскрытия его структуры.

## 8. Реализация итератора

Класс с указателем на текущий элемент, перегруженными `++`, `*`.

## 9. Объединение контейнеров

Оператор `+`, методы `merge`, вставка через итераторы.

## 10. Контейнер «ключ-значение»

Ассоциативный доступ (map, unordered_map).

## 11. Контейнер с операциями на одном конце

Стек (LIFO).

## 12. Какой объект является контейнером

Правильный ответ: `d (int mas[100])`.

## 13. Какой объект не является контейнером

Правильный ответ: `d (int mas)`.

## 14. Доступ в динамическом массиве

Произвольный доступ O(1) через адресную арифметику.

## 15. Доступ в списке

Последовательный доступ O(n) через переход по `next`.
