# Описание параметризированного класса-контейнера

В работе реализован шаблонный класс `LIST<T>`, представляющий собой односвязный список для хранения элементов любого типа `T`.  
Для организации структуры данных использована вспомогательная структура `Node<T>`, содержащая значение `value` и указатель на следующий узел `next`.

Внутреннее состояние класса `LIST` определяется двумя полями:

- `head` — указатель на первый узел списка  
- `size` — целочисленный счетчик количества элементов  

Для обеспечения навигации по контейнеру реализован вспомогательный класс `Iterator`.

# Определение компонентных функций

Все методы класса-контейнера реализованы как шаблоны:

- **Конструкторы:**  
  Реализован конструктор с параметрами для создания списка заданной длины, заполненного определенным значением, а также конструктор копирования для создания глубоких копий объектов.

- **Деструктор:**  
  Выполняет последовательное освобождение динамической памяти, выделенной под узлы списка, предотвращая утечки памяти.

- **pushback:**  
  Метод обеспечивает добавление новых данных в конец списка.

- **Перегрузка operator[]:**  
  Позволяет осуществлять доступ к элементам списка по их порядковому номеру. Реализована проверка границ: при некорректном индексе генерируется исключение `std::out_of_range`.

- **Перегрузка operator+:**  
  Выполняет операцию поэлементного сложения двух списков одинакового размера. В случае несовпадения размеров выбрасывается исключение `std::length_error`.

- **operator int():**  
  Предоставляет возможность получения текущего размера списка.

- **Операторы ввода-вывода:**  
  Перегружены `<<` и `>>` для взаимодействия с потоками.

# Описание пользовательского класса и его компонентных функций

Для работы с денежными суммами разработан класс **Money**.

- **Поля:**  
  Содержит `long roubles` и `int peny` (копейки).

- **Конструкторы:**  
  Включают конструктор по умолчанию, конструктор с инициализацией полей и конструктор копирования.

- **Перегрузка operator+:**  
  Обеспечивает корректное сложение сумм. Реализована логика нормализации: если сумма копеек достигает 100, производится инкремент поля рублей.

- **Оператор вывода <<:**  
  Обеспечивает форматированный вывод суммы через запятую. Реализовано добавление ведущего нуля, если значение копеек меньше 10 (например, 10,05).

# Функция main()

Тестирование программы организовано в два этапа внутри защищенного блока `try-catch`:

1. **Работа с типом int:**  
   Проверяется создание списка, ввод данных пользователем, сложение двух списков и корректность изменения элементов по индексу.

2. **Работа с классом Money:**  
   Демонстрируется создание списков денежных сумм, их вывод на экран и результат работы оператора сложения.

Для подтверждения работоспособности механизмов защиты от ошибок в коде предусмотрена попытка обращения к элементу по заведомо неверному индексу (100), что приводит к перехвату исключения и выводу информативного сообщения об ошибке.

# Объяснение результатов работы программы

Программа демонстрирует корректное поведение при работе как со стандартными, так и с пользовательскими типами данных. Результаты сложения целых чисел и денежных объектов соответствуют математическим правилам. При выполнении операции `+` для объектов `Money` подтверждена правильность работы логики переноса разряда из копеек в рубли. Система обработки исключений успешно предотвращает аварийное завершение работы при возникновении ошибок индексации или несовпадении размеров контейнеров.

# Ответы на контрольные вопросы

1. **Смысл использования шаблонов:**  
Позволяют создавать универсальный код, работающий с разными типами данных без дублирования.

2. **Синтаксис/семантика шаблонов функций:**  
`template <...>`. Компилятор генерирует конкретную функцию под тип аргументов.

3. **Синтаксис/семантика шаблонов классов:**  
`template <class T> class Name {}`. Создают семейство классов.

4. **Параметры шаблона функции:**  
Формальные типы или константы, заменяемые при вызове.

5. **Основные свойства параметров шаблона:**  
Могут быть типами или нетиповыми параметрами, должны быть уникальны.

6. **Запись параметра шаблона:**  
`template <class T, int N>`.

7. **Перегрузка параметризованных функций:**  
Возможна перегрузка шаблонов и обычных функций.

8. **Основные свойства параметризованных классов:**  
Генерация происходит при использовании; статические члены уникальны для каждого типа.

9. **Параметризация компонентных функций:**  
Методы шаблонного класса зависят от параметра `T`.

10. **Статус дружественных функций:**  
Могут быть обычными или шаблонными, могут зависеть от `T`.

11. **Виртуальные функции в шаблонах:**  
Разрешены в классах, но не в шаблонных функциях.

12. **Определение функций вне шаблона:**  
`template <...>` + `Class<T>::Method()`.

13. **Инстанцирование шаблона:**  
Генерация конкретного кода под тип.

14. **Этап генерации определения класса:**  
Происходит на этапе компиляции при использовании типа.
