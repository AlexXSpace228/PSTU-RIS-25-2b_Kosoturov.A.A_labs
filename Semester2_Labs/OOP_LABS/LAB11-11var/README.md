# Введение и постановка задачи

Целью данной лабораторной работы является создание консольного приложения, состоящего из нескольких файлов, с применением объектно-ориентированного подхода и использованием последовательных контейнеров стандартной библиотеки шаблонов (STL). Библиотека STL состоит из набора контейнерных классов и обобщенных алгоритмов, что позволяет универсально и эффективно управлять коллекциями данных.

В рамках нашего конкретного варианта необходимо было реализовать несколько подзадач, охватывающих работу с различными типами контейнеров (вектор, список, очередь/стек) как для стандартных типов данных (в нашем случае float), так и для пользовательских (тип Money). Основные операции, которые требовалось выполнить для каждого контейнера: вычисление среднего арифметического с последующим добавлением в начало контейнера, удаление элемента по заданному ключу и вычитание минимального элемента из всех элементов последовательности.

# Реализация базовых алгоритмов (Задача 1)

Для начала мы реализовали набор обобщенных глобальных функций, демонстрирующих базовую работу с контейнером std::vector для хранения вещественных чисел float. Вектор является непрерывной последовательностью в памяти, что позволяет быстро обращаться к элементам по индексу.

В коде реализованы функции генерации make_vector и печати print, а также основные алгоритмы: вычисление среднего srednee, добавление в начало add_begin, поиск минимума get_min, вычитание минимума subtract_min и удаление по ключу delete_by_key. При удалении по ключу используется итератор, так как метод erase вектора требует указания итератора на удаляемый элемент.

```C++
// Пример реализации функций для задачи 1
typedef vector<float> Vec;

float srednee(Vec v) {
    float s = 0;
    for (float x : v) s += x;
    return s / v.size();
}

void add_begin(Vec& v, float x) {
    v.insert(v.begin(), x);
}

void delete_by_key(Vec& v, float key) {
    for (auto it = v.begin(); it != v.end(); ) {
        if (*it == key) it = v.erase(it);
        else ++it;
    }
}
```

# Работа с пользовательским типом данных (Задача 2)

Для демонстрации гибкости STL был спроектирован пользовательский класс Money, описывающий денежную сумму в рублях и копейках. Чтобы контейнеры и алгоритмы могли корректно взаимодействовать с объектами этого класса, потребовалось перегрузить ряд операторов.

В классе Money реализованы конструкторы, а также перегружены:
•	Операторы ввода >> и вывода << для удобного взаимодействия с потоками.
•	Оператор сложения + и оператор деления / (на целое число) для вычисления среднего арифметического значения.
•	Оператор вычитания - для выполнения задания по вычитанию минимума.
•	Операторы сравнения < и == для корректного поиска минимального элемента и поиска элемента по заданному ключу для удаления.

```C++
class Money {
    long rub;
    int kop;
public:
    Money(long r = 0, int k = 0) {
        rub = r + k / 100;
        kop = k % 100;
    }
    // ... реализация перегруженных операторов ...
    bool operator<(const Money& m) {
        return rub < m.rub || (rub == m.rub && kop < m.kop);
    }
    bool operator==(const Money& m) {
        return rub == m.rub && kop == m.kop;
    }
};
```

Использование шаблонов существенно сокращает дублирование кода. Основная программа успешно демонстрирует, как один и тот же класс MyList инициализируется сначала типом float, а затем Money, выполняя все заявленные манипуляции. # Адаптеры контейнеров (Задачи 4 и 5)

Адаптеры контейнеров, такие как стек и очередь, не являются самостоятельными контейнерами, а переопределяют интерфейс базовых классов, строго регламентируя доступ к элементам. В лабораторной работе реализован собственный шаблонный класс очереди Queue на базе динамического массива, а также параметризированный класс-обертка ListQ для выполнения алгоритмов.

Поскольку очередь не поддерживает итераторы и произвольный доступ (мы можем работать только с началом и концом очереди), для выполнения сложных операций (вычисление среднего, поиск минимума) применяется метод выгрузки содержимого очереди во вспомогательный контейнер (вектор) с помощью метода to_vector(). После выполнения необходимых вычислений и модификаций над вектором, данные загружаются обратно в очередь методом from_vector(). Это классический паттерн работы с адаптерами, когда требуется произвести массовую модификацию или сложный поиск.

# Ответы на контрольные вопросы

1. Из каких частей состоит библиотека STL? Библиотека STL состоит из двух основных частей: набора контейнерных классов и набора обобщенных алгоритмов.
2. Какие типы контейнеров существуют в STL? Существуют последовательные и ассоциативные контейнеры.
3. Что нужно сделать для использования контейнера STL в своей программе? Необходимо включить в нее соответствующий заголовочный файл (например, #include <vector>).
4. Что представляет собой итератор? Итератор — это обобщение концепции указателей, он ссылается на элементы контейнера и обеспечивает доступ к ним.
5. Какие операции можно выполнять над итераторами? Разыменование (*), присваивание, сравнение на равенство и неравенство (== и !=), а также инкремент (++) для продвижения по контейнеру.
6. Каким образом можно организовать цикл для перебора контейнера с использованием итератора? Цикл организуется в форме for (i = first; i != last; ++i), где first — начало контейнера, а last — элемент за его концом.
7. Какие типы итераторов существуют? Входные, выходные, прямые, двунаправленные итераторы и итераторы произвольного доступа.
8. Перечислить операции и методы общие для всех контейнеров. Операции равенства == и неравенства !=, присваивания =, методы clear, insert, erase, size(), max_size(), empty(), begin(), end().
9. Какие операции являются эффективными для контейнера vector? Почему? Доступ по индексу и добавление/удаление в конец вектора, так как элементы хранятся в непрерывной памяти и не требуют сдвига.
10. Какие операции являются эффективными для контейнера list? Почему? Вставка и удаление в любой позиции, так как это двусвязный список, и требуется лишь переопределение указателей соседних элементов.
11. Какие операции являются эффективными для контейнера deque? Почему? Вставка и удаление первого и последнего элементов, так как двусторонняя очередь специально оптимизирована для этих операций с обоих концов.
