# Постановка задачи

## Задача 1
1. Создать последовательный контейнер.  
2. Заполнить его элементами пользовательского типа (тип указан в варианте). Для пользовательского типа перегрузить необходимые операции.  
3. Заменить элементы в соответствии с заданием (использовать алгоритмы `replace_if()`, `replace_copy()`, `replace_copy_if()`, `fill()`).  
4. Удалить элементы в соответствии с заданием (использовать алгоритмы `remove()`, `remove_if()`, `remove_copy_if()`, `remove_copy()`).  
5. Отсортировать контейнер по убыванию и по возрастанию ключевого поля (использовать алгоритм `sort()`).  
6. Найти в контейнере заданный элемент (использовать алгоритмы `find()`, `find_if()`, `count()`, `count_if()`).  
7. Выполнить задание варианта для полученного контейнера (использовать алгоритм `for_each()`).  
8. Для выполнения всех заданий использовать стандартные алгоритмы библиотеки STL.

# Анализ задачи

## Задача 1 (deque<idPair>)
- Создание двусторонней очереди `deque<idPair>` с объектами:  
  `(1,2.0), (3,4.0), (5,1.0), (2,3.0), (7,0.5)`
- Поиск максимального элемента через `max_element` и добавление его в конец очереди (`push_back`) (`task_1_subtask_3`)
- Удаление элементов, значения которых попадают в открытый диапазон `(k1, k2)`, с помощью `remove_if` и лямбда-предиката, затем `erase` (`task_1_subtask_4`)
- Вычисление среднего арифметического значений `value()` всех элементов и прибавление его к каждому элементу через `sum(avg)` (`task_1_subtask_5`)

## Задача 2 (stack<idPair>)
- Создание стека `stack<idPair>` с теми же объектами; вершина – `(7,0.5)`
- Поиск максимального элемента и добавление его на вершину стека: перекладывание во временный стек с отслеживанием максимума, восстановление исходного порядка и вставка максимума (`task_2_subtask_3`)
- Добавление среднего арифметического к каждому элементу: суммирование values через временный стек, вычисление среднего, обратное перекладывание с модификацией каждого объекта через sum(avg) (`task_2_subtask_5`)

## Задача 3 (set<idPair>)
- Создание множества `set<idPair>` с теми же элементами, автоматически упорядоченными
- Вставка максимального элемента: получение `*s.rbegin()` и вставка (дубликат игнорируется) (`task_3_subtask_3`)
- Удаление элементов, ключи которых принадлежат открытому диапазону `(k1, k2)`: через `upper_bound(k1)` и `lower_bound(k2)` с последующим `erase` (`task_3_subtask_4`)
- Добавление среднего арифметического к каждому элементу: вычисление среднего по `value()`, создание временного `deque` с модифицированными копиями (`sum`), очистка множества и вставка изменённых элементов (`task_3_subtask_5`)
