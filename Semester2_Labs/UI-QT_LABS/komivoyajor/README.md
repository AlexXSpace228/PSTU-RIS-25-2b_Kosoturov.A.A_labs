# Решение задачи коммивояжера

---

# 1. Постановка задачи

Целью лабораторной работы является разработка программы для решения задачи коммивояжера.

Задача коммивояжера заключается в нахождении такого маршрута обхода всех городов, при котором:

- каждый город посещается только один раз;
- маршрут начинается и заканчивается в исходном городе;
- суммарная стоимость пути является минимальной.

Для задания маршрутов используется ориентированный взвешенный граф.

Вершины графа представляют города, а ребра содержат стоимость перехода между городами.

В рамках лабораторной работы необходимо реализовать:

- создание графа;
- добавление вершин;
- добавление ребер;
- визуализацию графа;
- поиск минимального маршрута коммивояжера;
- вывод найденного маршрута и его стоимости.

Для разработки графического интерфейса использован фреймворк Qt.

---

# 2. Анализ задачи

Для решения задачи используется граф, представленный следующими структурами данных:

- список вершин;
- список ребер;
- список смежности.

Каждая вершина содержит:

- идентификатор;
- координаты отображения на сцене.

Каждое ребро содержит:

- начальную вершину;
- конечную вершину;
- вес ребра.

Для поиска маршрута используется рекурсивный перебор возможных путей.

В процессе работы алгоритма:

1. Выполняется обход графа.
2. Отмечаются посещенные вершины.
3. Вычисляется текущая стоимость маршрута.
4. Производится возврат в исходную вершину.
5. Выбирается маршрут с минимальной стоимостью.

# 2.1 Определение функций для реализации поставленных задач

## Функция `addVertex(QPointF pos)`

### Назначение функции

- создание новой вершины;
- добавление вершины в граф;
- сохранение координат отображения.

---

## Функция `removeVertex(int id)`

### Назначение функции

- удаление вершины;
- удаление связанных ребер;
- перенумерация оставшихся вершин.

---

## Функция `addEdge(int from, int to, int weight)`

### Назначение функции

- создание нового ребра;
- добавление веса перехода между вершинами.

---

## Функция `removeEdge(int from, int to)`

### Назначение функции

- удаление ребра между вершинами.

---

## Функция `updateEdgeWeight(...)`

### Назначение функции

- изменение веса существующего ребра.

---

## Функция `drawGraph()`

### Назначение функции

- визуализация графа;
- отображение вершин;
- отображение ребер;
- отображение весов ребер.

---

## Функция `drawArrow(...)`

### Назначение функции

- отображение ориентированного ребра;
- построение стрелки направления.

---

## Функция `tspHelper(...)`

### Назначение функции

- рекурсивный перебор маршрутов;
- проверка посещения всех вершин;
- вычисление стоимости текущего маршрута;
- поиск минимального маршрута.

Функция реализует основной алгоритм решения задачи коммивояжера.

---

## Функция `travellingSalesman(int start)`

### Назначение функции

- запуск алгоритма поиска маршрута;
- инициализация структур данных;
- возврат минимального маршрута и его стоимости.

---

## Функция `mousePressEvent(QMouseEvent *event)`

### Назначение функции

- обработка нажатий мыши;
- создание вершин;
- выбор вершин для добавления ребер.

---

## Функция `clickedVertex(QPointF pos)`

### Назначение функции

- определение вершины, выбранной пользователем.

---

## Функция `on_AddEdgeButton_clicked()`

### Назначение функции

- включение режима добавления ребер.

---

## Функция `on_TSPButton_clicked()`

### Назначение функции

# 2.2 Определение функции `main()`

Функция `main()` является точкой входа в программу.

В функции выполняются:

1. Создание объекта `QApplication`.
2. Создание главного окна приложения.
3. Отображение графического интерфейса.
4. Запуск цикла обработки событий.

Пример реализации:

```cpp
int main(int argc, char *argv[])
{
    QApplication a(argc, argv);

    MainWindow w;

    w.show();

    return a.exec();
}
````
