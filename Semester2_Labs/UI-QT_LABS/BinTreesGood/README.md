# Лабораторная работа  
## Работа с бинарными деревьями поиска

---

# 1. Постановка задачи

Целью лабораторной работы являлась разработка программного приложения для работы с бинарными деревьями поиска. Требовалось реализовать основные операции редактирования структуры дерева, а также обеспечить визуальное представление элементов и взаимодействие пользователя с программой.

В рамках работы необходимо было реализовать следующие функции:

- создание нового узла дерева;
- удаление узла;
- добавление элементов;
- редактирование структуры дерева;
- отображение дерева в графическом интерфейсе;
- выполнение основных алгоритмов обхода дерева;
- обеспечение корректной работы программы для различных наборов входных данных.

Программа должна была иметь кроссплатформенный пользовательский интерфейс и поддерживать визуализацию структуры дерева средствами графической библиотеки Qt.

Для реализации поставленной задачи использовался язык программирования C++ и фреймворк Qt.

---

# 2. Анализ задачи

## Общая структура программы

Программное приложение состоит из следующих основных частей:

- структура данных бинарного дерева;
- функции работы с узлами дерева;
- функции обхода дерева;
- графический интерфейс пользователя;
- модуль визуализации дерева.

Каждый элемент дерева содержит:

- значение узла;
- указатель на левое поддерево;
- указатель на правое поддерево.

Для реализации пользовательского интерфейса использовались классы Qt:

- `QMainWindow`
- `QGraphicsScene`
- `QGraphicsView`
- `QPushButton`
- `QTextEdit`

---

## Определения функций для реализации поставленных задач

### Функция создания узла

Функция предназначена для выделения памяти под новый элемент дерева и записи значения в узел.

Основные действия функции:

1. Создание нового объекта узла.
2. Инициализация значения.
3. Установка указателей левого и правого потомка в `nullptr`.
4. Возврат указателя на созданный узел.

---

### Функция добавления элемента

Функция реализует вставку нового значения в бинарное дерево поиска.

Алгоритм работы:

1. Сравнение нового значения со значением текущего узла.
2. Если значение меньше — переход в левое поддерево.
3. Если значение больше — переход в правое поддерево.
4. При достижении пустого указателя создаётся новый узел.

Таким образом сохраняется свойство бинарного дерева поиска.

---

### Функция удаления элемента

Функция обеспечивает удаление узла из дерева.

При удалении рассматриваются три случая:

1. У узла отсутствуют потомки.
2. У узла имеется один потомок.
3. У узла имеется два потомка.

В третьем случае выполняется поиск минимального элемента правого поддерева с последующей заменой удаляемого узла.

---

### Функция поиска элемента

Функция выполняет последовательный переход по дереву с использованием свойства бинарного дерева поиска.

Если искомое значение меньше текущего узла — переход выполняется влево, иначе вправо.

Поиск завершается:

- нахождением элемента;
- достижением пустого указателя.

---

### Функция обхода дерева

В программе реализованы основные виды обхода:

- прямой обход;
- симметричный обход;
- обратный обход.

Обход выполняется рекурсивно.

Результат обхода выводится в текстовое поле интерфейса.

---

### Функция визуализации дерева

Функция отвечает за отображение узлов и связей между ними.

Для отображения используются графические объекты Qt:

- окружности для вершин;
- линии для связей;
- текстовые элементы для значений узлов.

Координаты элементов рассчитываются относительно уровня вложенности узлов.

---

## Определение функции `main()`

Функция `main()` является точкой входа программы.

В функции выполняются следующие действия:

1. Создание объекта `QApplication`.
2. Создание главного окна программы.
3. Отображение пользовательского интерфейса.
4. Запуск основного цикла обработки событий.

Пример структуры функции:

```cpp
int main(int argc, char *argv[])
{
    QApplication a(argc, argv);

    MainWindow w;
    w.show();

    return a.exec();
}
````
