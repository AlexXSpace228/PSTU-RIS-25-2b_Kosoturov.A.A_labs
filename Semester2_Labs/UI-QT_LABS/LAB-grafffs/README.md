# Работа с ориентированными взвешенными графами

---

# 1. Постановка задачи

Целью лабораторной работы является разработка кроссплатформенного программного приложения для работы с ориентированными взвешенными графами.

В рамках работы необходимо реализовать следующие алгоритмы:

1. Обход графа в ширину (BFS).
2. Обход графа в глубину (DFS).
3. Алгоритм Дейкстры.
4. Алгоритм Флойда.

Программа должна обеспечивать:

- визуализацию графа;
- возможность добавления и удаления вершин;
- возможность добавления и удаления ребер;
- изменение весов ребер;
- работу алгоритмов как с графом варианта, так и с произвольными графами.

Для реализации графического интерфейса использован фреймворк Qt.

---

# 2. Анализ задачи

Граф представляет собой структуру данных, состоящую из множества вершин и ребер, соединяющих данные вершины.

Для хранения графа используется:

- список вершин;
- список ребер;
- список смежности.

Каждая вершина содержит:

- идентификатор вершины;
- координаты для отображения на сцене.

Каждое ребро содержит:

- начальную вершину;
- конечную вершину;
- вес ребра.

Программа реализована по объектно-ориентированному принципу. Основная логика работы с графом сосредоточена в классе `Graph`.

---

# 2.1 Определение функций для реализации поставленных задач

## Функция `addVertex(QPointF pos)`

### Назначение функции

- создание новой вершины;
- сохранение координат вершины;
- добавление вершины в контейнер вершин;
- создание новой строки списка смежности.

---

## Функция `removeVertex(int id)`

### Назначение функции

- удаление вершины по идентификатору;
- удаление связанных ребер;
- перенумерация вершин;
- корректировка списка ребер и списка смежности.

---

## Функция `addEdge(int from, int to, int weight)`

### Назначение функции

- создание нового ребра;
- сохранение веса ребра;
- добавление ребра в список ребер;
- добавление ребра в список смежности.

---

## Функция `removeEdge(int from, int to)`

### Назначение функции

- удаление ребра между двумя вершинами;
- обновление списка смежности.

---

## Функция `dfsHelper(...)`

### Назначение функции

- рекурсивная реализация обхода графа в глубину;
- отметка посещенных вершин;
- формирование результата обхода.

---

## Функция `bfs(int start)`

### Назначение функции

- реализация обхода графа в ширину;
- использование очереди для хранения вершин;
- последовательный обход смежных вершин.

Алгоритм BFS используется для поиска вершин по уровням удаленности.

---

## Функция `dfs(int start)`

### Назначение функции

- запуск рекурсивного обхода в глубину;
- формирование последовательности посещения вершин.

Алгоритм DFS используется для полного обхода графа.

---

## Функция `dijkstra(int start)`

### Назначение функции

- поиск кратчайших путей от заданной вершины;
- вычисление минимальных расстояний.

Алгоритм Дейкстры работает только для графов без отрицательных весов.

---

## Функция `floyd()`

### Назначение функции

- вычисление кратчайших расстояний между всеми парами вершин;
- построение матрицы кратчайших путей.

Алгоритм Флойда использует метод динамического программирования.

---

## Функция `updateEdgeWeight(...)`

### Назначение функции

- изменение веса существующего ребра;
- обновление списка ребер и списка смежности.

---

## Функция `drawGraph()`

### Назначение функции

- визуализация графа;
- отображение вершин;
- отображение направленных ребер;
- отображение весов ребер.

---

## Функция `drawArrow(...)`

### Назначение функции

- отрисовка ориентированного ребра;
- построение стрелки направления.

---

# 2.2 Определение функции `main()`

Функция `main()` является точкой входа в программу.

В функции выполняются следующие действия:

1. Создание объекта `QApplication`.
2. Создание главного окна программы.
3. Отображение графического интерфейса.
4. Запуск цикла обработки событий Qt.

Пример реализации:

```cpp
int main(int argc, char *argv[])
{
    QApplication a(argc, argv);

    MainWindow w;

    w.show();

    return a.exec();
}
````
